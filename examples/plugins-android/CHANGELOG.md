# Changelog

## v0.3.1 — 2026-08-05

egui 0.36: collapsed bottom bars no longer leave an invisible drag strip at the screen edge, and password fields now tell the keyboard not to learn them

## v0.3.0 — 2026-08-05

Every opened plugin gets its own bottom-bar tab, so a plugin viewport now has the full page height. The Plugins page became a launcher list, the nav scrolls horizontally, tabs close with the ✖ on the tab, and open tabs are restored on the next launch.

## v0.2.0 — 2026-08-05

Bottom-nav redesign: Plugin / Manage / Store tabs with a phosphor theme, per-plugin status dots, and the nav collapsing while the keyboard is up.
